# Third design review: substantive expansion and remaining evidence

The previous plan preserved the broad source families, but it still left too much inside broad component names and shared test language. This review adds a more concrete improvement and testing program across **every layer**, including subjects not repeated in the latest messages. It also fixes several mathematical, timing and inference ambiguities. This is an improved research specification; no production trading system or empirically validated edge is claimed.

The 153 parent contracts remain the architecture. They now have eight explicit experiment phases, alongside 191 named refinements: **344 experiment units and 2,752 phase records**. These numbers count proposed experiments and phase specifications, not independent models, successful tests or required deployed components. Independent specialist heads, shared representations and simple joint competitors must be compared fairly.

## Material findings and changes

| Finding | Previous limitation | Correction and verification route |
|---|---|---|
| TR-01 Individual testing was too implicit | Ten-part parent cards and generic test families did not expose each small hypothesis's sequence of evidence | Every parent/refinement now has P0–P7 with local cases, targets, challengers, metrics and decision consequences. A named test alone does not satisfy a source case. |
| TR-02 “Best” had insufficient operational meaning | A more complex model or a higher local score could appear to justify improvement without identifying the bottleneck | Separate data/definition/information/model/policy comparisons; actual-input lineage; learning curves; planted/null controls; useful-effect thresholds; scoped oracle diagnostics; fixed confirmatory rules. |
| TR-03 Vega flow was omitted | O16 listed delta/gamma/vanna/charm but not the vega flow explicitly present in the DTM conversation | Added a separate vega CVD/OHLC experiment, correct USD/unit-IV versus USD/vol-point units and independent future-surface/receiver tests. |
| TR-04 IV/skew/VX coverage was too broad | One C15 card and a generic C16 description obscured substantially different mechanisms and data needs | Explicit ATM, smile, delta-skew, curvature, tenor, event, variance-gap, strip, intraday-change, leverage, 0DTE and cross-IV heads; separate VIX forward/surface/VVIX, daily VX and distinct VX-option dependency. |
| TR-05 VIX feasibility was underused | The existing audit established files, but did not show whether actual intraday call/put sets supported a calculation | Read three quote days, compute illustrative parity/IV at nine cuts, preserve quote/rate/clock limitations and pair inconsistencies. OI expiries exceed the request-folder label; quote/OI coverage must be separate. |
| TR-06 Variance/excursions could be treated as paths | Calibrated excursion summaries alone do not determine barrier order | Typed forecast capability masks and explicit dynamics/survival requirements; same-excursions/opposite-order fixtures. |
| TR-07 Contact-horizon labels were ambiguous | Pre-contact reach by t+h could be multiplied with post-contact outcomes extending to contact+h | Fixed common end for pre-contact targets; separately identified contact-origin targets; no-contact versus censor distinction. |
| TR-08 Waiting-value rewards could double count | A full-trade value could be mistaken for one-step reward plus overlapping continuation | Incremental marked-net or semi-Markov macroaction contracts; fees once; continuation at actual terminal state/time; same account boundary and occupied-time comparison. |
| TR-09 OI evidence could be assimilated twice | O07 already uses some flow subsequently passed into O08 | One coherent conditional assimilation path; duplicate-evidence certainty fixture; endpoint calibration remains separate from unidentifiable intraday holdings truth. |
| TR-10 Marketable-fill wording used the next quote | Waiting for a new post-arrival quote can change execution time and price | Use standing venue BBO at actual simulated arrival; separate strategy-information and venue-outcome clocks, feed lag and outbound lag. |
| TR-11 Geometry and uncertainty could be conflated | Strike-cluster spread, mapping/model uncertainty and contact tolerance were described as one width | Separate fields and explicitly defined scenario regions; freeze the actual event band and compare matched width/count/distance. |
| TR-12 A DAG could still imply all work on every tick | Logical dependency ordering did not specify multi-rate execution, expiry or overload behavior | Independent risk/order lane; cached completed versions; bounded optional work; explicit cadence/TTL trials; atomic pre-dispatch reservation. |

| TR-14 Frozen versus adaptive evaluation conflicted | F12 forbade all telemetry-driven fitting while G10 allowed a preregistered adaptive policy | Baseline freezes parameters; an adaptive challenger freezes its update rule and evaluates the complete causal trajectory. |
| TR-15 Future-test extension was statistically incomplete | Extending until an ordinary confidence interval reaches desired precision/target can invalidate the intended coverage | Fixed endpoint as initial protocol; justified group-sequential/time-uniform alternatives require explicit assumptions and estimand. Risk halts retain the whole record. |
| TR-16 Standalone gain could become an excessive gate | An exact service or interaction-only input need not be profitable/predictively superior alone | Mandatory semantic/causal integrity, but allow preregistered neither/A/B/A+B comparisons and explicit invariant/risk roles; require integrated evidence before promotion. |
| TR-17 The early baseline left too many choices open | E0 was an experiment outline rather than a reproducible reference | Exact initial sampling, inputs, models, observations, entry/bracket/time exits, timing stress and required fee/account manifest. It is an engineering benchmark, not an adopted strategy. |

## Improvements beyond volatility

The [measurement experiments](experiments/M.md) separate source size cohorts from adaptive/continuous size marks, true CVD OHLC from closing totals, and exact trade profiles from bar allocation. They test causal profile anchors, multimodal shelves/valleys, buy/sell/delta channels, TPO versus dwell, robust VWAP bands, swing confirmation, BBO net recovery, intensity, effort efficiency and aggression-memory decay.

The [Context experiments](experiments/C.md) preserve different Jumbo path branches and opening types while comparing learned clock, activity and auction/change-point ranges. Conditional/analog and joint excursion models update remaining movement from the observed prefix. Auction acceptance, value migration, event responses, realized reversion/expansion and session transitions receive separate tests. An eventual day label or gamma sign cannot replace those observables.

The [Location experiments](experiments/L.md) compare every source family and its improvements at matched geometry and candidate density, then distinguish a better generator from a better scorer. Internal EQ continuation, small options nodes, in-between learned proposals, actual profile anchors, dynamic versus frozen targets, retest lifetimes and source-only receiver entries remain independently eligible hypotheses.

The [options](experiments/O.md) and [cross-market](experiments/X.md) experiments separate raw information, surface/Greek accuracy, holdings scenarios, mechanical changes, node dynamics, topology, chain identity and joint representations. They include explicit NDX/NDXP/QQQ and SPX/SPXW/SPY comparisons, price versus cohort-flow SMT, directed source-only transmission, and each supported global/slow-context family with publication gates. Acquired daily gold/dollar context is now explicitly routed without assuming intraday GLD/OG data.

The [selection](experiments/G.md), [policy/risk](experiments/P.md) and [research](experiments/V.md) experiments compare model diversity, calibration/support, reach/runner duration, cost-dependent value, occupancy-aware waiting, actual action selection, fills/shortfall, full-position exits, re-entry and account/cash consequences. Detailed [Response](experiments/R.md) remains later, but its source variants and prefix/entry/exit tests are explicit now, including the distinct failed-auction and resqueeze branches.

## What was actually checked in this review

All ten component-family documents, common contracts, dependency schedule, implementation/validation/backlog and governing requirements were reviewed for the expanded design; affected evidence, data and risk documents were reconciled. All five original conversations had already been read fully in the source review; this pass rechecked their 122 finding rows and explicitly assigned experiment routes. The original 712-source and 114-external matrices were retained and regenerated for the changed document locations. The [five new primary checks](THIRD_REVIEW_RESEARCH.md) bring external finding records across the two research documents to 119. This is not a fresh claim of rerendering all 580 source PDF pages during this pass.

The completed [VIX audit](review/third-review/VIX_FEASIBILITY.md) read **261,970 quote rows**, three accompanying OI files, nine decision cuts and 18 expiry/cut combinations. Illustrative IV inversion was possible in all 18 under stated assumptions; several whole-pair parity sets were inconsistent, and uncertainty remains explicit. The [27 finite worked-example assertions](review/third-review/DESIGN_EXAMPLES.md) checked reward arithmetic, path order, target clocks, standing quotes, duplicate evidence, geometry, Greek units and the review-only IV solver. Neither activity is a fitted strategy test or proof of signal quality.

The reproducible [planning audit](review/document_qa.json) checks required documents, parent fields, exact source/requirement routes, local links and preserved source hashes. The [third-review audit](review/third-review/review_qa.json) checks all 344 units/2,752 phase records, local definitions, 122 explicit conversation routes, five research entries and bounded-example/data evidence. Structural checks do not prove semantic completeness or empirical success. The pre-review authored package and manifest are preserved in `review/third-review/planning-baseline.zip` and `baseline-manifest.json`.

## What remains unknown

The strongest future signal, best supported model, achievable daily net and required data scale remain empirical questions. Useful-effect thresholds, numerical runtime budgets and exact account fees/permissions are set or certified before their dependent implementation experiments; they are not inferred from a plan. Missing quote conditions/receipts, incomplete wings, uncertain publication vintages, unacquired constituent/TRF/depth/VX-option streams and undisclosed source formulas retain their explicit gates. The excluded old workspace archive remains excluded.

The requested outcome of this review is a much more concrete, broadly improved and falsifiable plan. Execution of the proposed trading-model program is separate work. “Best supported under tested conditions” is the acceptance standard; the quality framework prevents an impressive specification, large model count or reputation claim from being mistaken for evidence.
