# F06/F07 finite quality and support engineering protocol

Status: frozen before dependent implementation. The registration report pins the
protocol, literal expectations, source review and code snapshot. This family shares
one combined full-suite worker with F05–F08; actual use is conservatively charged
to every participating family and retained under one physical execution identity.

Scope: F06, F06.GAP_RECOVERY, F07 and F07.AGE_SUPPORT shared deterministic
infrastructure. Source preparation is reports/f06-f07-source-preparation.json:
19 source IDs, all 32 local phase rows, and 40 named prepared cases. Retain all
those routes and limitations. No raw market read, source/Pine execution, archive
inspection, model fitting, economic trial, orders, acquisition or planning edit.

The reference inputs are finite synthetic int64 nanoseconds, exact integer
values and immutable source/definition/policy identities. Registered fixture
thresholds are example contracts, not market-calibrated TTLs or live promises.
Input clocks retain known_at, source observation, local receipt, value-change
and source-liveness separately. Fresh equal economic observations have new
lineage; copied snapshots must name an already admitted content origin and
cannot refresh economic observation, value-change or liveness clocks.

F06.RAW quality facts precede normalization; F06.SEMANTIC follows normalization.
Both produce field/operation/interval incidents with severity and exact evidence.
Hard semantic failures dominate statistical advisories. No anomaly model is
implemented in this batch. A missing field invalidates only its mandatory
consumers; optional consumers retain an explicit omission. Integrity lanes stay
unconditional. Gaps are defined against a declared observation stream, not an
absence of trades. No-event, missing packets, halted market, stale content and
optional timeout are different reasons.

A book-gap incident and a trade-history incident are distinct facts. A matched
book recovery closes only future book-state blocking; it neither deletes the
past bad interval nor repairs missing flow or aggregates spanning that interval.
A clean-looking update alone cannot recover a book. Certified flow replay or an
explicit new measurement epoch is a separate action. No reconstruction from
future observations. Existing BookReducer/RecoveryCertificate behavior is reused
as a consumer integration boundary rather than rewritten.

F07 chooses the most recent eligible-at-cut observation vector causally. The
latest invalidating revision cannot resurrect the prior valid value. Preserve
candidate lineage and rejection reasons even when no value is admitted. Field
age is based on the economic observation, not row receipt. Each operation has a
registered maximum economic age, source-silence limit, clock-uncertainty bound,
required capability and incident policy. No generic valid bit grants signing,
valuation, forecasting and execution at once.

A joined result contains per-field candidate/admitted IDs, versions, observation
and receipt clocks, age/uncertainty, liveness evidence, coverage state and reasons.
Joint support is separate: a bounded observation-time span and (when required)
a supplied complete prior-data movement witness are explicit policies. All
fields passing TTL does not imply contemporaneity. Missing/incomplete movement
support remains unsupported; sparse observations cannot manufacture an exact
underlying path. No new input clock is synthesized by joining.

Instrument/field coverage uses an explicitly supplied point-in-time universe and
source capabilities. A field store is not the parent contract universe. Union
identical overlapping observations once while retaining all acquisition IDs;
conflicting observations fail explicitly. Full daily OI is not full intraday
quote coverage. Missing OI is not zero. Report exact observed-known-OI numerator
and denominator, missing-OI count and missing quote fields separately. An OSI
symbol cannot substitute for payoff/definition identity.

Reference: independent finite full scans and explicit quality interval union.
Challenger: bounded per-field/per-operation materialized eligibility intervals,
invalidated only by applicable field/incident/liveness changes. Lookup uses the
interval timeline, not another full scan hidden behind an index name. Bound
retained events and intervals; fail explicitly on saturation without eviction or
silent loss. Checkpoint identities bind the same inputs/policy/definitions.

Compare every field value, ID, version, age, support mask, omission, joint reason
and affected interval at every fixed cut, including suffix deletion, delayed
correction, reordering equivalent admissions and restart. Instrument actual row
checks, interval builds/lookups, affected fields and optional downstream arithmetic
calls. Report build and query work separately. Fresh actual wall/CPU/RSS telemetry
comes from timed deterministic toy work; no synthetic cost is called measured,
and there is no speed threshold. The golden reference-count example scans six
supplied observations for each of three fields at each of five cuts: 90 actual
candidate-row checks. The materialized view performs 15 instrumented field
interval lookups and zero source-candidate scans during those queries; its build
work is additionally counted and reported, never omitted from the comparison.

Root runs the single combined F05–F08 suite only after one complete static bug
review of all changed code/callers/tests and one consolidated fix pass. Proposed
compatible combined envelope, subject to root registration: at most three family
attempts, 600 CPU seconds total; 180 soft/190 hard CPU seconds, 4 GiB address-space
and 240 wall seconds per attempt. Existing F04 evidence is immutable. Preserve
failure, code snapshot, assertion names, full output and actual resource telemetry.

This batch supplies shared engineering fixtures, not every vendor adapter or
real cohort. INV-12 original hardware transcript remains unresolved; INV-11
retains limited audit semantics. Actual source liveness/receipt distributions,
full option quote/condition/listing universes, calibration and intended-history
certification remain open. P5 needs the actual C/O/X/L/G/P consumers; P6 requires
the later complete E0–E5 policy; P7 requires authorized future capture. All 40
prepared source cases remain explicit even where this batch only implements a
toy contract analogue rather than the original market observation.
