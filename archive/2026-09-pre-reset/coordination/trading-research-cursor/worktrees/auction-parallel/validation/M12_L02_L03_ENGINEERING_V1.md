## Scope and ownership

The minimum E0 output joins nine current 06:00–09:00 range locations with four prior-RTH OHLC references. C01/L01 owns H/L/EQ/25%/75%; L02 owns H+W/2, H+W, L−W/2, L−W; M12 selects the exact prior completed RTH and L03 publishes its O/H/L/C locations. The union retains thirteen source identities even when prices overlap. The E0 coordinator, not these modules, freezes an opportunity set and applies a policy.

These are geometry and reference measurements. Neither range exhaustion nor an extension ratio carries a reversal probability. Learned reach/role/overshoot models, C06 excursion alternatives, broader profile/value/delta references, source-specific grids beyond the registered subset, and UP-M12/UP-L02/UP-L03 comparisons remain explicit follow-on obligations. Passing the finite cases does not close whole units, P0–P7, E0 economics or source replication.

The shared neutral `ClockSelection` / `RangePrimitive` port follows `reports/c01-l01-design.json:shared_port_proposal`, with Herschel owning `foundations/range_primitives.py` and `context/range_adapter.py`, including the single F10 adapter contract. No parallel custom clocks, raw-price types or registries are introduced by these consumers. C01 owns range geometry; M12 owns prior-reference selection; L02 owns edge formulas. Consumers use `select_clock` with actual `IntervalGraph` and `interval_name` (graph/node as-of validation and one exact named span, alongside separate Calendar resolution), `primitive_from_shared_bar` by retained publication ID, `primitive_registry_links`, and `publish_range_batch`; root freezes their final field/signature contract before registration.

## Evidence and clocks

`ClockSelection` records the raw instrument definition/lifetime, calendar version, session key and trading date, source-clock variant, half-open formation interval, predecessor session key where applicable, and calendar-known time. It is a projection of a verified F03 interval/session. A source label such as London, RTH or fixed EST cannot silently select a different timezone/window. Prior means the recorded previous eligible session in a complete calendar sequence, not date minus one or the last row incidentally present.

`RangePrimitive` carries that clock, F09 source bar version, F10 source evidence/anchor versions, source definition/reset epoch, observation cut, publication time, revision/predecessor, exact OHLC ticks, coverage/watermark versions, per-field support/status and original event timestamps (directly or through exact parent evidence). A plain immutable snapshot is not a certificate. The adapter must verify the retained factory-certified F09 `SharedBar`, final time-bar state, exact interval and raw domain, coverage, price support and publication availability before constructing a supported result.

The minimal implementation consumes sealed time ranges. A first eligible print occurring later than the scheduled open is still a valid session open when complete evidence proves no earlier eligible print; a first observed print after missing opening data is not certified as the open. Sealed-window publication necessarily waits for completion/watermark. A distinct early-opening-prefix service, if later needed, must prove prefix coverage and source completeness under its own contract; this draft does not backdate sealed-session output.

Per-field support is essential. Exact original coverage spans must be recovered from the retained F09 publication request and bound to the exact factory publication; `SharedBar` alone retains only a coverage version and duration. Public checkpoint history retains the request, and F09 restore replays it. Root assigns Herschel a minimal checked public F09 publication-request accessor so the common adapter need not copy full checkpoint history per primitive. M12 consumes only the resulting certified primitive; it does not access private F09 history. Caller-supplied spans cannot certify a primitive. A complete prefix from window start through the first eligible event can certify O despite a later gap; a complete suffix from the last eligible event through window end can certify C despite missing opening data. Endpoint batches must still resolve to exact price with supported history and source finality. H/L require full-window coverage. Thus [300,10800) coverage with last10799=180 yields C180 while O/H/L are partial; [0,10740) with first0=120 yields O120 while C/H/L are partial. An unresolved first batch with differing prices can make O unknown while H/L remain exact; an ambiguous last batch can make C unknown. Interior event order ambiguity alone need not invalidate exact OHLC. Current 06–09 E0 geometry declares H/L as required fields. A complete prior E0 set declares O/H/L/C. Missing prior O/C means that complete set is unavailable; supported individual H/L remain explicitly available for diagnostics or separately registered subsets. Empty complete coverage means no executions, not zero price.

For every derivation, input-known is the maximum actual source and calendar availability. It must not exceed the decision cut. Actual completion must not precede the cut; published known time must not precede completion. The result is unavailable before its publication or at/after the declared horizon. The source formation timestamp is not publication. A later correction creates a new revision at its actual availability, preserving old candidate cuts and target bindings. No last-chart-bar/timenow lookup, future-final OHLC or mutable named preset enters a past decision.

## Deterministic definitions

All coordinates are exact rational ticks in one explicit raw instrument lifetime. Points are ticks multiplied by the exact instrument tick size; a raw identifier match without provider/venue/definition/lifetime is insufficient. Same-contract prior references can be used directly. A prior old-contract reference requires an explicit valid F08 mapping/bridge with its uncertainty and availability; absent such a mapping, it cannot become a current-contract executable price or compatible gap.

For L≤H, W=H−L. E0 range-derived candidates require W>0. An inverted range is invalid; a flat completed range yields structured unavailability, preserving independent prior references. Upper edge extension is H+kW and lower is L−kW. For L=1000,H=1100,k=1.33, these are 1233 and 867; internal x=1.33 instead gives 1133. The upper edge projection has normalized x=2.33. The broader hand-derived ratios 1.33/1.66 preserve the exact source convention but do not expand the E0 universe.

Raw source geometry stays unrounded. A line at p with E0 contact tolerance one tick has contact interval [p−1,p+1], including fractional endpoints. An execution policy may later map it to an executable tick and alias equivalent actions, but may not merge source births, rewrite geometry or count correlated source origins as independent evidence. Region bounds are sorted after lower-side reflection. Any preset ratios, coordinate convention and generator definition are part of immutable identity; colors and display toggles are not.

M12 reference types distinguish session first eligible trade, first observed trade, bar open, last eligible session trade, official settlement, midpoint and VWAP. Equal numbers do not merge their identities/publication histories. The final close comes from the last eligible event before the half-open end, never the first outside bar's close. Settlement is an official observation with report/publication/revision evidence; a daily close or learned estimate cannot fill its absence. The broader formula fixtures preserve body25=.75C+.25O and range25=L+.25(H−L) separately, and gaps declare both typed references and compatible coordinates.

L03 keeps prior 09:30–16:00 NY RTH and verified shortened-session variants distinct from the full session, current 06–09 window, overnight range and profile anchors. A verified shortened session is not automatically incomplete; missing expected observations are. Exact raw OHLC does not require a profile. Missing M04/M05 value/delta support suppresses those fields only. Source RTH-only freshness disregards ETH sweeps for that interpretation; the full-session challenger records ETH touch/breach/ordered return on the same underlying reference without deleting it. An ETH trade451 above prior high450 proves breach only; a later trade449 permits an ordered return-below state. Neither proves hidden stops or inventory. No global used-level exclusion is introduced.

## F10 publication and state

Use F10 typed `EvidenceVersion`, `AnchorVersion`, `BirthKey`, `Geometry`, `ObjectRevision`, `PublicationClock` and `AtomicBatch` through the common adapter. Exact source IDs, generator/definition, raw instrument, immutable anchors and object role discriminator determine source birth; price alone does not. Evidence parents must exist at the cut. Corrections retain revision/supersedes chains and invalidate/degrade dependent support through F10 semantics. The adapter does not manufacture support by taking arbitrary caller scalars as certified evidence.

The registry definition declares the finite generator versions, candidate/resource limits and lifecycle/visit rules. A batch that cannot fit rejects before mutation, without silent truncation or partial eligible sets. Publishing the same identity/payload is an exact retry; conflicting same-identity payload is rejected. Frozen candidate cuts, earlier as-of queries and checkpoint/restart must reconcile. Same-price origins remain distinct candidates until a separate action projection applies a registered execution policy.

Contact observations and future labels are downstream. A trade jump from108 to112 across[109,111] records gap crossing but no traded contact. A trade at110 followed by113,116 contacts that region without proving reversal. Full-horizon no reach remains in the denominator; missing tail is censored. A touched object and far untouched object remain traceable. Ordered future departure ends at the original t+15min for E0; no horizon starts over at contact.

E0's entry contact uses native-MBP-1-derived BBO midpoint only at completed one-minute cuts. These geometry modules cannot replace it with tick-touch entry, vendor bbo-1m or retrospective intrabar contact. Eligible native events still drive future labels, fills/protection and timing. These distinctions are interface assertions, not an implementation of the execution policy in this scope.
