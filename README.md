# Trading research

Research toward an adaptive NQ decision process: context, location, response and execution, with independently measured components.

Phase 1 setup implementation and the acquired historical census are complete: **1,742 session dates searched; 18,747 observed setups**. Input limitations are explicit; these counts do not establish fills or profitability. See the [measurement report](/workspace/implementation/reports/phase1-live/historical-measurement/MEASUREMENT_REPORT.md) and [family/audit tables](/workspace/planning/phase-1-live/PHASE.md).

- [Shared wiki](/workspace/wiki/index.md): source methods, objects, glossary and current evidence.
- [Program roadmap](/workspace/planning/ROADMAP.md): agreed boundaries, dependencies and scope.
- [Phase 1.5 implementation pack](/workspace/planning/phase-1-5/README.md): rule reconstruction and finite setup discovery.
- [Phase 2 implementation pack](/workspace/planning/phase-2/README.md): context, intraday forecasts, native options and method experts.
