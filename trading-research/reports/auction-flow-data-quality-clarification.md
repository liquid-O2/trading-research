# Acquired data and provider quality flags

The accepted source checks do not show missed downloads in the nine inspected windows. Every selected physical scan read its complete expected row population. The reported `gap_rows` count is the number of stored records carrying the provider's `F_MAYBE_BAD_BOOK` bit, not a count of missing rows, files, dates, or separate outages. Its old machine-readable name remains unchanged in frozen evidence.

Databento defines bit 4 as an unrecoverable gap detected in the upstream channel. A file can be downloaded completely and still contain that provider warning. Multiple subsequent records may carry it, so the count cannot determine the number or duration of interruptions. [Provider flag definitions](https://databento.com/docs/standards-and-conventions/common-fields-enums-types).
