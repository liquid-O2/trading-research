# P2-05 — Fit the range-path and auction-session experts

Subphase: `04-context-mechanisms`. Blocked by: P2-04, P2-02A. Absorbs the former P2-06 (auction, day-type and session-quality expert) under the 2026-09-16 plan cleanup; every acceptance key of both cards is kept below.

## Delivers

Two separately fitted context experts on the common engine of P2-02: `range_path` (remaining up and down excursion, first-passage time distributions, break topology and post-break acceptance) and `auction_session` (current operational auction and day-state descriptors, future transitions, session opportunity quality). Each has its own feature and target recipes, artifact, support record, ablations and chronological evaluation against constant, session-frequency and price-only baselines. When done, a reader can trace one forecast of each expert from its serialized row through its feature parents to a native receipt, and can see every unsupported head or negative incremental result retained with its honest status.

## Steps

1. For each expert, implement the exact feature and target recipes, units, horizons, state semantics and missing or censored populations, with the sensitive positive case and the negative control from the contract's worked examples.
2. Fit the declared linear, hinge, classifier, regression and quantile heads with causal parent forecasts and fixed grids; keep each expert's artifact and support separate.
3. Run the constant, session-frequency and price-only baselines, the specified group ablations, the chronological evaluation and the deterministic native diagnostics on the declared slice, inspect the output, then the full run.
4. Trace one actual output per expert through its serialized schema, feature and stage parents and native receipt; run the verification below and write immutable evidence.
