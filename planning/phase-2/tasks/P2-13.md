# P2-13 — Fit the method context experts (eight source methods)

Subphase: `06-method-experts`. Blocked by: P2-05, P2-07, P2-12, P2-02A. Absorbs the former P2-14 to P2-20 under the 2026-09-16 plan cleanup: one task, one common engine, one configuration and one artifact per method. Every acceptance key of the eight cards is kept below, grouped per method.

## Delivers

For each of JJ-TBR, GB-FAIL, GB-VWAP, GB-SCALP, SIRES, SAINT-AMT, MEMBER-TWO-REASONS and KEANI-OPEN-ABOVE-VALUE: a separately fitted expert configuration and artifact that uses the method's Phase 1.5 source adapter and its row in METHOD_EXPERTS.md, predicting branch occurrence, conditional utility and path, session, branch and reference suitability and timing, on an occurrence grid plus pre-opportunity rows at the actual source qualification clock, with complete no-setup rows and separate masks. Generic fitting stays in the shared engine; nothing is pooled across methods. A reader can, for every method, trace one output row to its source adapter and native receipt and see every low-support branch reported as the declared prior with all counts.

[METHOD_EXPERTS.md](/workspace/planning/phase-2/METHOD_EXPERTS.md) (the per-method rows and the conditional-plan schema), [MODEL_FITTING.md](/workspace/planning/research-program/MODEL_FITTING.md), [EVALUATION.md](/workspace/planning/research-program/EVALUATION.md), [OUTCOMES.md](/workspace/planning/research-program/OUTCOMES.md), [DATA_CONTRACTS.md](/workspace/planning/research-program/DATA_CONTRACTS.md), [ASSURANCE.md](/workspace/planning/research-program/ASSURANCE.md), and the method pages [JJ-TBR](/workspace/wiki/method-jumbo-tbr.md), [GB-FAIL](/workspace/wiki/method-green-bird-failure.md), [GB-VWAP](/workspace/wiki/method-green-bird-vwap-continuation.md), [GB-SCALP](/workspace/wiki/method-green-bird-directional-scalps.md), [SIRES](/workspace/wiki/method-sires-thesis-flow.md), [SAINT-AMT](/workspace/wiki/method-saint-amt.md), [MEMBER-TWO-REASONS](/workspace/wiki/method-member-two-reasons.md), [KEANI-OPEN-ABOVE-VALUE](/workspace/wiki/method-keani-open-above-value.md) for the exact source predicates. ## Steps

1. Implement the shared method-expert path once (dataset rows on the shared snapshots, occurrence grid and pre-opportunity targets with deterministic first-future-qualifying-setup selection, masks, support gates, ablations, per-method report) and the first method end to end as the vertical slice, with the sensitive positive case and the negative control from the contract.
2. Add the seven remaining methods as configurations plus the method-specific predicates their pages require; consume causal upstream forecasts including the OI B0/B1/B2 identities; preserve source clocks and the selected-rule cutoff.
3. Run the declared slice for all eight methods, inspect the output, then the full run; measure one method's runtime and peak RSS first and budget workers against the cgroup.
4. Trace one actual output per method through its serialized schema, feature and stage parents and native receipt; run the verification below and write immutable evidence, with one family report per method.

## Acceptance

Shared, checked for every method:

- [ ] A01: No all-history selected rule or in-sample upstream forecast enters historical training/test rows.
- [ ] A02: A low-support branch returns the declared prior/baseline and all counts, not a fitted-success claim.
- [ ] A03: Pre-opportunity rows are built at the actual source qualification clock before any subsequent outcome, and occurrence rows are never mixed with them.

Per method, each key holds its three checks:

- [ ] A04 JJ-TBR: (a) all eight branches retain separate occurrence/suitability and timing masks; (b) pre-open features cannot use the final overnight purge/path explanation; (c) outbound deadline/P-zone baseline identity stay source constrained.
- [ ] A05 GB-FAIL: (a) sweep-entry and reclaim alternatives keep their own available clocks; (b) prior hour/day/week/month source references remain distinguishable; (c) supplemental refinement is not counted as an independent entry method.
- [ ] A06 GB-VWAP: (a) the source-long prerequisite is not silently relaxed by a favorable context score; (b) a custom short variant keeps a custom source label; (c) VWAP age/anchor and remaining expansion are consumed and ablated.
- [ ] A07 GB-SCALP: (a) both direction branches have mirrored fixture coverage; (b) incomplete proprietary automatic admission remains explicit; (c) later confirmation delay is a measured input history, not a future label.
- [ ] A08 SIRES: (a) all 12 branches and rare/zero cells appear in support outputs; (b) operational day-type probability is not a known final day type; (c) different flow sequences and gamma/KG1 assumptions remain explicit.
- [ ] A09 SAINT-AMT: (a) HTF/LTF availability and agreement are independent; (b) four route labels are not collapsed into generic trend/balance; (c) source control/retest prerequisites persist under context scoring.
- [ ] A10 MEMBER-TWO-REASONS: (a) the two reasons must have independent evidence parents; (b) a reaction-period HVN is not an independent second reason; (c) touch history uses resolved prior reactions only.
- [ ] A11 KEANI-OPEN-ABOVE-VALUE: (a) before A-period completion the complete-A predicate is unknown; (b) sequence features cannot use a future developing VAH; (c) six observations cannot satisfy the fitted-support gate.

Evidence:

- [ ] A12: Evidence includes command exit codes, artifact hashes, coverage/unknown counts, runtime, actual output inspection and the task’s declared limitations. All predecessor receipts verify.
- [ ] A13: EVIDENCE_MATRIX.json resolves every acceptance key and assigned failure case to actual code, executed commands, hashed evidence and inspected output under ASSURANCE.md; artifact/identity/command forgeries fail.
- [ ] A14: The assigned silent-failure probes pass with sensitive positive and negative controls, honest native/unknown/job counts, and no stale evidence. Return review-ready artifacts; subphase admission additionally requires the coordinator’s matching passing GATE_REVIEW.json.
- [ ] A15: The evaluation pairs the expert against the applicable source context baseline from P2-02A (as well as the constant, session-frequency and price-only baselines) and reports upgrade or retained under the promotion gates; the source read is retained when not beaten.

Assigned research cases: S07, S08, S11, S15, S17, S18, S19, S20, S21, S23, S28, S32 (see SILENT_FAILURES.md). The verifier cases S01 to S03 are cited from the P15-01 bound evidence, not re-probed here.
