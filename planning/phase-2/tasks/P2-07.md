# P2-07 — Fit the flow-memory and cross-market experts

Subphase: `04-context-mechanisms`. Blocked by: P2-04, P2-11. Absorbs the former P2-08 (native cross-market and spot-IV coupling expert) under the 2026-09-16 plan cleanup; every acceptance key of both cards is kept below.

## Delivers

Two separately fitted context experts on the common engine of P2-02: `flow_memory` (rewarded aggression, failed pushes, defended persistence and transition forecasts) and `cross_market` (native related-market divergence, lead/lag, spot/IV coupling and NQ path contribution). Each has its own feature and target recipes, artifact, support record, ablations and chronological evaluation against constant, session-frequency and price-only baselines. A reader can trace one forecast of each expert to a native receipt and see every unsupported head retained with its status.

## Steps

1. For each expert, implement the exact feature and target recipes, units, horizons, state semantics and missing or censored populations, with the sensitive positive case and the negative control from the contract's worked examples.
2. Fit the declared heads with causal parent forecasts and fixed grids; keep each expert's artifact and support separate.
3. Run the baselines, the specified group ablations, the chronological evaluation and the deterministic native diagnostics on the declared slice, inspect the output, then the full run.
4. Trace one actual output per expert through its serialized schema, feature and stage parents and native receipt; run the verification below and write immutable evidence.
