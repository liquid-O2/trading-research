Planning is complete enough to expose these choices. They are not a request to re-explain the system. No locked user decision is reopened. Each question changes an event, object, population or faithful-source claim. Proposed implementation details can be settled by the later implementer. Until a definition resolves, retain raw observables and a blocked-definition report row; do not manufacture a faithful result.

Q01 and Q05 directly block the shared reaction comparison and exact Jumbo P-zones. Other questions block only the named branches. Literal, fully specified indicator variants can proceed separately. A source-formula answer may be “unavailable”; that preserves the blocker and an explicitly named approximation, rather than turning the approximation into the source benchmark.
