# Descriptive auction-state transitions

Family: **auction-order-flow**. Measure faithful objects; experiment with named upgrades in Phase 1.

## Evidence and source rules

[the-math-behind-auction-market-theory.pdf, pp.5–14](../../../sources/documents/discretionary/the-math-behind-auction-market-theory.pdf#page=5) proposes B balance, A absorption, D discovery, E replenishment exhaustion and W withdrawal. Its AAPL LOBSTER10-level/20,000-event matrix is illustrative; thresholds are absent. Local value has repeated two-sided executions and low aggression; absorption combines high effort, low progress and hold/refill. [average-unprofitable-trader.pdf, pp.13–14,19–26](../../../sources/documents/discretionary/average-unprofitable-trader.pdf#page=13) asks whether each confluence addition helps. [data-engine.pdf, pp.3–6](../../../sources/documents/discretionary/data-engine.pdf#page=3) requires operational definitions and all-success/all-failure comparison; its unspecified C-score is not an approved macro platform.

## Computability and faithful reconstruction

MBP-1 permits BBO/execution proxies, not exact all-depth submissions/cancellations. Descriptive transition counting is feasible after definitions freeze.

Use source state names with explicit proxy qualifiers, raw component features and known_at. Resolve overlaps/unknown state before row-normalizing counts. Exhaustion here is replenishment failure, separately named from declining aggression and huge-delta/no-result prints.

## Upgrades to measure

These are proposed experiments, not attributed source rules. The user requests stronger objects and independent comparisons. [Develop Trading Model.md, L13–31](../../../sources/documents/conversations/Develop%20Trading%20Model.md)

## Phase 1 outcomes

Occupancy, dwell, transition counts/support, state disagreement, subsequent path and year stability. Preserve unknown/missing observations instead of fabricating a state.

Use [the common measurement contract](measurement-contract.md) for availability, denominators, discovery and confirmation. A source percentage is a claim to recompute. It is never a pass threshold.
