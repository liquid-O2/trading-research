## Computability and faithful reconstruction

Each mechanism emits objects/features, event paths and family reports with explicit lineage. These are proposed common interfaces for later implementation, not existing software or computed results.

Object identity includes family, mechanism, variant, instrument/contract, formation interval, anchor, bounds/units and definition version. Store created_at, known_at, confirmed_at, invalidated_at and superseded_by separately. Every feature cutoff precedes the first outcome observation. Carry raw source-formula and causal benchmark differences explicitly.

Event rows retain eligible population, trigger, first touch/break, approach, rearm, source horizon, censor time, price path offsets and all competing outcomes. Distinguish point touch, zone entry, strict breach, return, reject, acceptance and no-event. For OHLC ties retain unknown order or lower/upper probability bounds; use trades only where present. Never invent an intrabar sequence. Q01 must settle shared reject/hold/rearm thresholds; source-specific rules remain separately named.

## Upgrades to measure

These are proposed experiments, not attributed source rules. The user requests stronger objects and independent comparisons. [Develop Trading Model.md, L13–31](../../../sources/documents/conversations/Develop%20Trading%20Model.md)

- Fit descriptive thresholds, quantiles, bins and clock choices on pre2024 discovery only. Write the chosen finite variant set before reading confirmation outcomes. No Context/Location/Response predictor fitting.
- Confirmation is2024 through each family’s last complete2026 observation where available. Report post2024-only families without pretending they have earlier discovery; use source-fixed variants or an explicitly reserved chronological split.
- Show full family sample and matched overlap; missingness is not a zero outcome. For zones show density, width, age and initial distance. Compare variants on common eligible sessions and event rules, with clustered-by-session uncertainty and yearly support.
- Proposed evidence: session-bootstrap95% intervals, paired session differences and multiple-comparison disclosure. Null or worse experiments are valid measured results. No P&L, Sharpe or best-backtest acceptance.

## Phase 1 outcomes

One report row per faithful/experimental variant: family | variant | n | faithful disagreements | experiment status | report path. Reports expose eligible sessions, events/touches and outcome-specific denominators. n means mature eligible outcome units for the row and its unit must be stated; it is not a universal trade count.

Faithful disagreements count unresolved differences against independently adjudicated geometry/event fixtures or source rules. Source hardcoded empirical rates are compared as claims, not equality targets. Expected source defects are named and reviewed; a future-informed source display cannot pass as an early feature. Required-definition blockers or missing mandatory-family reports prevent scientific pass. Accepted deferred mechanisms show reason and emitted prerequisites. Full-depth identity claims can be deferred without adding a data prerequisite.

Use [the common measurement contract](measurement-contract.md) for availability, denominators, discovery and confirmation. A source percentage is a claim to recompute. It is never a pass threshold.
