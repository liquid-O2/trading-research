## Computability and faithful reconstruction

Computed causal node snapshots can supply lifecycle and touches. The single screenshot is a visual definition example, not a historical dataset of premarked nodes.

Persist immutable node versions: creation/update/invalidation, parent ID, bounds, strength, expiry mass, product, sign scenario and quote support. Match versions without using future geometry. Record merge/split and disappearance; retain failed and untouched nodes.
