# Sister-asset value and single-print arrivals

Family: **CVD-SMT**. Measure faithful objects; experiment with named upgrades in Phase 1.

## Evidence and source rules

[code-1-thesis.pdf, pp.5–7](../../../sources/documents/discretionary/code-1-thesis.pdf#page=5) defines IOD: sister reaches/rejects prior balance or VAH first and the laggard reacts faster/further; RFZ: sister fills a single-print area before target reaches its own. Relative distance from value and unconfirmed highs/lows are separate hypotheses. The user requests reactions at cross-asset nodes before local arrival. [Design robust feature levels.md, user turns L682–700,827–834,904–924](../../../sources/documents/conversations/Design%20robust%20feature%20levels.md) [conversation_export (1).md, Turns7,11,15–17,19](../../../sources/documents/conversations/conversation_export%20%281%29.md).

## Computability and faithful reconstruction

OHLC plus per-asset VP/TPO and options-node histories support object-arrival events on actual common coverage. A daily cash index cannot supply minute-level arrival truth.

Match object kinds, not equal prices. Record each asset’s distance to its own confirmed object, first arrival/reaction and NQ path afterward. Pairing and reaction must be known then. Keep extreme SMT, IOD, RFZ and options-node lead events separate.

## Upgrades to measure

These are proposed experiments, not attributed source rules. The user requests stronger objects and independent comparisons. [Develop Trading Model.md, L13–31](../../../sources/documents/conversations/Develop%20Trading%20Model.md)

- **distance/time-normalized leader lag**, **all-pairs versus3–4-asset breadth**, **object-kind/scale ablations**, **mapped-futures/ETF proxies**, **trade versus OHLC arrival**.

## Phase 1 outcomes

Lead/lag distribution, local nonarrival, time to local touch, NQ excursion after sister arrival, reversal/continuation, missing objects and yearly support. Include sister touches followed by no NQ response.

Use [the common measurement contract](measurement-contract.md) for availability, denominators, discovery and confirmation. A source percentage is a claim to recompute. It is never a pass threshold.
