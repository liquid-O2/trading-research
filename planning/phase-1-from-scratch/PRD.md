# Phase 1 PRD: measure and compare the source object set

The supplied sources mix disclosed rules, drawn examples, hardcoded probabilities and unpublished formulas. Using them directly would give later research an unverified object set. Phase 1 will reconstruct the faithful objects, measure their failures as well as successes, and compare named upgrades on common outcomes. The result is a set of inspectable family reports, not a trading strategy or a promise of positive P&L.

This PRD is derived from the completed [wiki](wiki/index.md), especially [authority](wiki/research-contract.md), [measurement](wiki/measurement-contract.md) and [inventory](wiki/inventory-and-availability.md). [SOURCE_MECHANISMS](SOURCE_MECHANISMS.md) maps every reviewed finding to its mechanism. The source review gate and subsequent wiki read are recorded in [REVIEW_LEDGER](REVIEW_LEDGER.md) and [wiki/log](wiki/log.md).

## User and intended outcome

As the researcher building an NQ system, I need to see what each source object actually does, which named alternatives change those results, and where coverage or definitions limit a conclusion. Every required family must have an observable benchmark/experiment report with honest support, source disagreements and year stability. I must be able to trace a report row back to its source rule, definition version, input population and event paths.

The later research target remains one account, one NQ mini, $2,000 average daily net including zero-trade eligible days and a $1,000 daily loss cap. NQ is execution; ES is information. All sessions are in scope, with no position held across the day boundary. Those locks do not turn Phase 1 into a P&L backtest. [Authority](wiki/research-contract.md).

Retain width, balance, clean edges, prior RTH value/open position and sister SMT as known then. Compare experimental labelers; do not train a predictor.

- Compute trade-CVD, OHLC-CVD, participant-separated trade-CVD, participant-separated OHLC-CVD and gamma CVD after their definitions resolve. SMT is continuous and multiscale, with NQ trade-level and 3–4-asset OHLC constructions.

## Scientific acceptance

The single all-family command prints `family | variant | n | faithful disagreements | experiment status | report path`. Each report contains source benchmark and named experimental rows, complete denominators, discovery/confirmation boundaries, same-population differences and stability by year. Every row states its unit of n. Failures, nonreturners, untouched objects, missing data and ambiguous intrabar order remain observable.

A faithful implementation has no unexplained disagreement against independently expected examples and disclosed rules. A published win rate or source sample total is a claim to recompute, not an equality target. No required mechanism disappears behind a generic family total. Unresolved faithful definitions, missing mandatory branches, leakage or invalid coverage prevent pass. Explicitly unidentifiable/deferred mechanisms retain their reason and emitted prerequisites.

An experiment need not improve a metric to pass measurement. Report better/null/worse or insufficient support against the frozen benchmark. Do not select the best confirmation result, retune it on that slice and call it confirmed. Distinguish descriptive quantile/threshold estimation from forbidden Context/Location predictor training. [Measurement contract](wiki/measurement-contract.md).
