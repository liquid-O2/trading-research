# Phase 1 execution contract

Status: planning only. This contract is for later authorized Grok-through-Cursor execution under the project’s selected model and working rules. The command below is a proposed interface; it does not exist as a result of this session and has not been run.

## One outcome

Produce a reproducible, source-cited measurement and comparison report for every in-scope Jumbo, day-type, auction-order-flow, CVD-SMT, volatility and options-data mechanism: faithful constructions and named upgrades share declared outcome tables, use the longest honest family samples with frozen2024–2026 confirmation where available, retain causal availability and complete failure/no-event populations, expose source disagreements and support by year, and emit only the measured objects/columns needed by later Context and Location. A source probability or the later P&L target is not a pass criterion. Required unresolved definitions or omitted branches prevent scientific completion; named unavailable/unidentifiable and later-phase mechanisms retain explicit evidence and reasons.

## Single pass command

Run from the checkout root after the proposed entry point is implemented:

```sh
phase1 measure --all --verify
```

It must print:

```text
family | variant | n | faithful disagreements | experiment status | report path
```

The command succeeds only when all required reports and in-scope comparisons pass the [SPEC](SPEC.md) evidence rules. It reuses still-valid slice evidence and checks the full dependency closure. A null, worse or honestly low-support experimental result can pass measurement. A missing required result, leakage, stale evidence, unresolved faithful definition or unexplained reconstruction disagreement cannot. Do not turn a blocked P-zone/CVD/node formula into a successful approximation row.

## Execution boundary and stop rule

Work the dependency frontier in the [PRD’s local ticket list](PRD.md#independently-checkable-stories). Each ticket is one vertical slice: definition → real data → coverage/statistics report. Make the smallest complete change that makes that story true. Demonstrate the independent expected result and real-data path before expanding computation. Freeze variant choices before confirmation. Reuse accepted evidence while its relevant inputs and assumptions hold.

Must not change: raw sources (`sources/documents/`), raw data (including original `/workspace/data` and `/workspace/sources`), or `archive/`. Do not execute bundled indicator code. No MBP-10/MBO prerequisite, trades, P&L optimization, trained Context/Location/Response predictor, acquisition, excluded-product review or extra infrastructure. Phase 2/3 design remains [one page](wiki/deferred-context-location.md).

There is **no wall-clock kill**. The successful pass command, with these invariants satisfied, is the stop rule. If verification fails, preserve the exact failure, input identities and report evidence and reassess before editing again; do not begin an automatic repair cycle. Review progress at least every30 elapsed minutes against an actual acceptance condition, including all earlier work in the same allowance. Definition questions in [QUESTIONS](QUESTIONS.md) remain blockers until answered or explicitly resolved in the execution scope.
