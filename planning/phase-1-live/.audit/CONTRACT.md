# Construction audit contract

Read-only for workers. Do not edit this file.

## Exit predicate

`planning/phase-1-live/CONSTRUCTION_AUDIT.md` lists every live family id that has a SPEC registry entry or a report JSON. Each row uses `audit ∈ {pass, fail, unbuilt, not-measurable}`. No remaining `fail` that the parent can still fix. Skylit is `not-measurable`. Parent writes the markdown. Workers write only their slice TSV.

## Do not

- Score `RULES.md`.
- Start Phase 2.
- Add tickets.
- Edit `sources/`, `archive/`, `planning/phase-1-fable/`, `planning/phase-1-from-scratch/`.
- Re-run families (parent does that).
- Edit implementation code (parent does that).

## Checks per id

1. Function matches SPEC/wiki (clock, reset, side, multiplier, bar type).
2. Fixture on synthetic or one dated session. Real arithmetic, not a hardcoded `pass: true`.
3. `leakage_count = 0` on measured rows. `known_at` before outcome.
4. Spike rule. Range H/L is not a one-tick isolated explosion versus the 1s median in the box. Options `mapped_nq` ratio is not a one-print jump when a mapped experiment row exists.
5. Range H/L from the intended bars. RTH-only objects do not include ETH garbage.
6. Delta/CVD reset matches SPEC/wiki (`flow.cvd.trade` resets 18:00 ET).

## Options (wiki/options-nodes.md as it is now)

- Faithful = native-on-native. `mapped_nq` is experiment only.
- QQQ/SPY spot = that ETF's 1-minute close. NQ.OPT spot = NQ.
- NDX/NDXP/SPX/SPXW: no invented cash minutes. Theta quotes have no underlying column. EOD daily cash distance and/or sister QQQ/SPY rows labeled `sister_of`. Never call QQQ price NDX spot.
- Row fields: product, strike, spot_at_t, distance points and ATR, tagged/near, known_at, OI_vintage.
- Missing quotes = hole. Product row stays.
- Skylit = not-measurable.

## Verdicts

- `pass`: construction matches, fixture ran, leakage 0, spike_flag clean or n/a.
- `fail`: a check failed. Cite file:line.
- `unbuilt`: SPEC/wiki id, no report and no function.
- `not-measurable`: locked, unpublished, or data absent. Skylit stays here.

## Output

Write exactly one TSV at the path in your brief. Header:

```
family	id	audit	fixture	leakage	spike_flag	notes
```

`spike_flag` is `clean`, `flagged`, or `n/a`. `fixture` is `pass`, `fail`, or `none`. Notes stay one line. Evidence is a path or file:line, not a paragraph.

Cover every report JSON in your family directories and every SPEC §5 id for those families. Wiki faithful objects with no report are `unbuilt` unless already `not-measurable` in SPEC.
