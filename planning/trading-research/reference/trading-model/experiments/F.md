# Data, clocks and state: individual experiment phases

All phase records below are **planned trading-system checks**, not completed test results. Each parent retains its ten-part specification; named refinements isolate particular information, definitions or model/policy alternatives. They do not imply one process or model per row.

[Phase rules and model quality](../SPECIALIST_EXPERIMENT_PROGRAM.md) govern chronology, metrics, interactions, useful effects, failure decisions and future testing. The [complete upgrade paths and specific child bindings](../UPGRADE_PATHS.md) and [implementation constructions](../UPGRADE_CONSTRUCTIONS.md) bind every unit below. Every listed local case needs separate named assertions at implementation; a test bearing the component name alone is insufficient.

| Unit | Kind | Individual target |
|---|---|---|
| [F01](#f01) — Immutable ingestion and schema decoding | measurement-or-integrity | `CanonicalEvent` candidates plus partition manifest, counts, schema fingerprints and rejected-row reason codes. No predictive label/calibration; missing required schema yields quarantine. |
| [F01.DECODER](#f01-decoder) — Independent decoding reference | measurement-or-integrity | Exact instrument/time/side/size/action fidelity on supported records. |
| [F02](#f02) — Instrument, option contract and settlement registry | measurement-or-integrity | Typed instrument registry and `valuation_eligible`, `execution_eligible`, `outright/spread/unknown` flags; no learned target. Uncertainty is unresolved metadata, never a probability of identity. |
| [F02.PAYOFF](#f02-payoff) — Contract-style payoff and calendar cases | measurement-or-integrity | Correct contract valuation domain and executable dollar units. |
| [F03](#f03) — Trading calendar, session and boundary engine | measurement-or-integrity | `SessionKey`, open/close/holiday/transition events, eligible-day calendar, time-to-boundary and source-clock variants; no trained labels. |
| [F03.SESSION_CASES](#f03-session_cases) — Session and boundary completeness | measurement-or-integrity | Exact session/range/forced-flat timestamps. |
| [F04](#f04) — Availability ledger and causal replay clock | measurement-or-integrity | Reproducible ordered event batches, watermarks, availability provenance, delay/clock-uncertainty flags and replay hashes. No predictive target. |
| [F04.SCHEDULER](#f04-scheduler) — Multiple update clocks and atomic publication | measurement-or-integrity | Causal decisions at measured computation/dispatch times. |
| [F05](#f05) — Event identity, trade conditions and side normalization | measurement-or-integrity | Eligible trade and normalized book-event views with raw/decoded flags, reported aggressor or unknown, source order, inclusion/exclusion reason, correction lineage and stable event ID. Unknown volume remains in total and separate uncertainty counters. Flagged flow coverage and trusted book validity are separate fields. |
| [F05.CROSS_VENDOR](#f05-cross_vendor) — Vendor trade/quote semantic reconciliation | measurement-or-integrity | Matched record identity and side/size uncertainty at actual supported timing. |
| [F06](#f06) — Quality, gaps, stale data and quarantine | measurement-or-integrity | Quality mask and severity `informational/dependent-feature-block/execution-block`, incident record, coverage durations. Statistical anomaly score is advisory with its own uncertainty. |
| [F06.GAP_RECOVERY](#f06-gap_recovery) — Gap-specific state recovery | measurement-or-integrity | Known quality state and causal recovery/abstention behavior. |
| [F07](#f07) — As-of joins and coverage tensor | measurement-or-integrity | Joined snapshot with every input row/version and age; `CoverageMask`, observed-OI fractions and invalid/missing reasons. No assumption that absent contract equals zero. |
| [F07.AGE_SUPPORT](#f07-age_support) — Coverage and age propagation | measurement-or-integrity | Correct availability and support of each consuming horizon. |
| [F08](#f08) — Futures rolls and equity adjustments | measurement-or-integrity | Contract mapping, return series, roll event, adjusted display series, object translation record. No future target except downstream returns. |
| [F08.ROLL_PARITY](#f08-roll_parity) — Roll and adjustment invariance | measurement-or-integrity | No artificial range/flow/option-node jump from a roll or split. |
| [F09](#f09) — Causal bars and multiresolution aggregation | measurement-or-integrity | Bar schema with interval, observed-duration/volume, final/provisional flag, reset and quality; quote bars distinct from trade bars. CVD bar extrema derive from ordered cumulative trades, not price candles. |
| [F09.ACTIVITY_BARS](#f09-activity_bars) — Event and activity bars | measurement-or-integrity | Same-clock future path information after each bar becomes known. |
| [F10](#f10) — Versioned market-object and event registry | measurement-or-integrity | `MarketObject`, immutable transition log and active-set query as-of time; every revision references prior version. Unknown formation prevents activation. |
| [F10.LINEAGE](#f10-lineage) — Object and event identity integrity | measurement-or-integrity | Complete candidate and outcome denominator. |
| [F11](#f11) — Feature, prediction and fold artifact store | measurement-or-integrity | Reproducible feature/prediction tables and manifests with row keys, upstream lineage and permissible training intervals. Missing artifact returns explicit failure, not automatic stale cache reuse. |
| [F11.INPUT_AUDIT](#f11-input_audit) — Actual model-input lineage | measurement-or-integrity | Feature availability and actual use by the registered experiment. |
| [F12](#f12) — Historical/live adapter and receipt telemetry | measurement-or-integrity | Receipt-latency distributions, raw live archive, canonical stream, parity reports and quality incidents. No live trading implied by read-only shadow capture. |
| [F12.PARITY](#f12-parity) — Historical and captured-live equivalence | measurement-or-integrity | Reproducible output and timing assumptions when future capture is authorized. |
