## Reading the diagnostics

The consumed-input ledger identifies the conditions used for the displayed branch. Shared scanner stage panels also retain events that the branch may not require. A false stage with an `unknown` clock has no observed event timestamp; it does not turn a decided no-setup result into an unknown. An n/a input cannot change a rejection already proved by a known violated condition. False optional configuration flags are not highlighted as failures.

All clock labels are ET. Prior-reference clock labels may refer to earlier dates; complete timestamps and field provenance are in the linked job. Personal management/order units remain outside setup qualification.
