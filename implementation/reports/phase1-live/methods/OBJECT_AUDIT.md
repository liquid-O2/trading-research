# Object-by-object implementation coverage audit

September 12, 2026. All 166 live O contracts were manually compared with their registered recipe implementations. This inventory identifies reusable work and missing obligations; it is not a count of 166 certified implementations. See [full findings](FULL_AUDIT.md) and [implementation plan](IMPLEMENTATION_PLAN.md).

Inspection classes: **partial** = material contract behavior absent or incorrect; **bounded primitive** = useful limited computation/audit whose native construction remains external; **supplied scalar only** = consumes a value without its required producer; **source hole handler** = preserves an undisclosed definition; **source hole handler partial** = preserves that limitation but still has documented validation/assembly gaps. A hole handler is useful work, not a recovered source engine.
