# Historical method cohorts: status and backfill boundary

The current method-pack-v1 run reports historical `N=0` for all 12 methods. This does not mean no market episodes occurred. Under C05/C07, `N=0` means no candidate population was identified because the required source-defined inclusion selector is missing. The 201 tests, 1,316 recipe fixture/mutation checks, and 12 exit-zero method commands validate the implementation and algebra; synthetic fixtures are deliberately excluded from historical counts. No supplied episode manifest was provided either. See the [method-pass index](/workspace/implementation/reports/phase1-live/methods/index.md) and [C05/C07 rules](/workspace/planning/phase-1-live/FORMULAS.md:143).

Backfilling NQ bars/trades, ES peer OHLC/trades, or macro values supplies observations. It does not decide which observations were a source method attempt. A valid historical cohort needs a frozen manifest naming method/branch, NQ as the primary traded instrument, the 2020+ span, optional ES context, data ownership, source version, candidate rule, and recipe versions. The selector must retain every proposed attempt, including losses, misses and failed prerequisites, before later outcomes are examined. Each candidate then needs source-compatible objects, exact identity, coverage, and causal `known_at` times. C04 scores pass/fail/unknown; C07 reports `p/f/u`, `n=p+f`, and `N=n+u`. A missing selector is a source hole with `n=0`, not a fabricated unknown per day or a `no_candidates` result. ES MBP is only needed when the selected branch requires ES liquidity; pre-2020 RTY is outside this scope.

The written discovery rules were audited rather than accepted as a blanket unknown:

| Method | What FORMULAS actually permits | Historical result now |
|---|---|---|
| JJ-TBR | Literal ranges/projections are computable; context, location and confirmation selectors are missing. | `source_hole` |
| GB-FAIL | Complete five-minute comparisons are computable for *verified* references, but session, bias, admission and several reference-clock selectors remain missing. This is a diagnostic subprocedure, not a full cohort. | `source_hole` |
| GB-VWAP | Session bounds, breakout-bar definition, VWAP reset/basis and risk/admission evidence are missing. | `source_hole` |
| GB-SCALP | No repeatable source-complete scalp selector. | `source_hole` |
| SIRES / SAINT-AMT / MEMBER-TWO-REASONS | Core auction, flow, balance, node, confirmation or risk selectors are incomplete. | `source_hole` |
| KEANI-OPEN-ABOVE-VALUE | Value/imbalance settings, timing tolerance, developing selectors and source risk/target records are incomplete. | `source_hole` |
| REFILL-STUDY / JETBUNDLE-STATES | Source cluster/grade/lifecycle or AAPL 10-level classifier inputs and thresholds are absent. | `source_hole` |
| STOIC-DATA | Full trading recipe and custom macro/C-score/cycle/trend-strength rules and thresholds are unpublished. | `source_hole` |
| STOIC-RISK | Printed ladder arithmetic is reconstructable, but prior-process admission, Monte Carlo construction and other transitions are not. | `source_hole` |

Three examples make the boundary concrete. For JJ-TBR, a 06:00–09:00 NQ range, quadrants, sweeps and projections can be calculated. A JJ candidate still requires the source-selected context, exact location, confirmation mode, risk and objective, with branch identity and availability before entry; geometry alone cannot seed attempts. For GB-VWAP, NQ data can support finished Asia/London highs and a later retest calculation once source session bounds and the exact breakout bar are supplied. A 09:30-reset comparison VWAP cannot stand in for the required source reset/basis; M03 explicitly leaves that case unknown. For STOIC-DATA, the cohort unit is a declared process/review block, not a trade. It requires inclusion frozen before the sample, all eligible observations (including losers) retained, pre-decision features, separated outcomes, an aggregate winner/loser comparison, and a revision using only prior observations. Its macro branch additionally needs point-in-time release vintages, a declared historical comparison, and supplied/custom indicator, cycle, C-score and trend-strength rules. A raw macro backfill cannot create that process record.

Remaining work is to define and construct the historical candidate population. `discovery.py` currently emits a branch-level selector hole and `run_historical()` returns no candidates. A source-complete definition or timestamped supplied episodes can be scored while retaining their own denominator. Another possible study is to freeze explicitly researcher-chosen selection rules, implement their historical discovery, and report that cohort as a named research variant. Those choices cannot silently stand in for the original author's rules. Until a candidate definition is fixed, the source-method historical status remains `source_hole`, while raw object backfills remain useful diagnostics.

The [macro backfill](/workspace/implementation/reports/phase1-live/macro-backfill/README.md) now supplies 20 series with historical versions and verified initial CPI/payroll publication clocks. It improves the available input layer; it does not choose the method's candidate population or fill unpublished custom indicator rules.
