- 2026-09-16 Digest memo: full-file sha256 of inputs >= 8 MiB memoized by (absolute path, size, mtime_ns, inode, device) in-process and in an append-only JSONL store (`TR_FILE_DIGEST_CACHE`, default /workspace/.cache/file-digests, gitignored; `off` disables). An entry is only ever a digest this function computed for the same signature; files under 8 MiB are always hashed (tests rewrite small fixtures in place). Cache keys of the frozen event cache are unchanged: the values are the same digests (parity below).
- 2026-09-16 Incremental prefixes: `FastEventWindow._prefix(start, end)` keeps per-`start` state and extends it as `end` grows (membership `start <= at and end <= end and known_at <= end` is monotone in `end`; a smaller `end` rebuilds a temporary). Per-price sums are exact int64 (volumes are ints in every cached window: checked on a real window, 108,298 rows, all `(str, int, int, int)`, 5,074 prices with one spelling each) rendered as `Decimal(int)`, equal to the pinned `Decimal(0) += int` sums; pv/p2v are exact Decimal sums, so the order of addition is immaterial. A window with a second spelling of a price or a non-int volume falls back to the pinned Decimal loop (tested).
- 2026-09-16 Coverage memo: a full minute's state depends on `end` only through `row['known_at'] > end`, so the end-independent state is computed once per minute per window; partial minutes are computed the pinned way. Each call returns fresh objects (a mutated result cannot poison the memo: tested).
